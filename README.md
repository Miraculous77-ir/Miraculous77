# Miraculous77 v2
نسخهٔ اولیهٔ توسعه‌یافته برای GitHub Pages.

## امکانات اضافه‌شده
- جستجوی قسمت‌ها
- فیلتر فصل و زبان
- جدیدترین قسمت‌ها
- قسمت‌های آینده و شمارش معکوس
- علاقه‌مندی‌ها با localStorage
- تاریخچه/ادامه تماشا با localStorage
- اشتراک‌گذاری قسمت
- صفحه جزئیات هر قسمت
- لینک پخش و دانلود با کیفیت‌های مختلف
- ساختار آماده برای اخبار و معرفی سریال
- رابط واکنش‌گرا برای موبایل
- تغییر زبان رابط فارسی/انگلیسی پایه
- فونت Vazirmatn

حساب کاربری، کامنت، موسیقی و اپلیکیشن عمداً در این نسخه وجود ندارند.

## مدیریت محتوا
اطلاعات قسمت‌ها و اخبار داخل `data.js` قرار دارد. تصاویر را می‌توانی داخل `assets/` قرار دهی و مسیرشان را در همان فایل عوض کنی.
